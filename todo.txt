Local, before pushing
1. ☐ Rewrite history (git rebase -i → squash to initial commit)
2. ☐ Final sanity: cargo test && cargo clippy --all-targets && cargo fmt --check && cargo doc --no-deps && cargo publish --dry-run
3. ☐ Optional: cargo package --list to eyeball what ships

GitHub
4. ☐ Create oxidecomputer/codespace, add the remote, push main
5. ☐ Confirm rust.yml CI goes green

crates.io
6. ☐ Logged in as you, email verified on crates.io
7. ☐ New API token scoped to crate codespace, permissions publish-new + publish-update only
8. ☐ Add it as the CARGO_REGISTRY_TOKEN Actions secret on the repo

Release
9. ☐ git tag v0.0.1-alpha.1 && git push origin v0.0.1-alpha.1
10. ☐ Watch the Publish release workflow finish

Verify
11. ☐ crates.io shows 0.0.1-alpha.1 with you as owner
12. ☐ docs.rs build succeeds
13. ☐ GitHub release created with the changelog notes; badges resolve
